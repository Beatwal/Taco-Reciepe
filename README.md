# Taco Recipe Web App 

A simple Node.js and Express web application that displays taco recipes based on user selection. Built with **Express**, **EJS**, and **body-parser**.

---

## Features

- Choose between **Chicken Taco**, **Beef Taco**, or **Fish Taco**.
- View detailed ingredients, toppings, and quantities for each taco.
- Simple frontend using **EJS templates**.
- Dynamic rendering based on user selection.

---

## Tech Stack

- **Node.js** – JavaScript runtime
- **Express.js** – Web framework
- **EJS** – Templating engine
- **Body-parser** – For parsing form data
